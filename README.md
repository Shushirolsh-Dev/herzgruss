# Herzgruss

A warm, editorial German-language birth congratulations page, built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The greeting intentionally avoids inventing a baby's name, gender or photo.
